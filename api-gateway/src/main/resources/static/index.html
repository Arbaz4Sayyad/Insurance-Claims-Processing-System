Healthcare Insurance & Claims Processing System (IECS)

Engineered a distributed Healthcare Claims Processing System across 11 microservices using Spring Boot, Spring Cloud Gateway, Docker, PostgreSQL, Kafka, and Resilience4j; built an interactive Developer Portal for real-time API evaluation & automated eligibility rule validation.

🏛️
Welfare & Insurance Automation

Digitizes how citizens apply for government assistance (SNAP Food Support, Medicaid, and Child Care) without manual paperwork.

🔐
Secure Registration & Privacy

Citizens sign up securely with AES-256 encrypted SSNs and role-based permissions (Admin, Caseworker, Citizen).

📊
Income & Expense Verification

Captures monthly salary, household dependents, and medical costs with cross-service Kafka event coordination.

⚙️
Instant Rules Engine

Automatically evaluates income against federal poverty guidelines in milliseconds to determine eligibility & benefit amounts.

🔄 End-to-End Claim Lifecycle Sequence

            

              

                
1

                

                  
Citizen Authentication & Onboarding (User Service)

                  
Citizen signs up on /api/auth/signup and authenticates at
                    /api/auth/signin receiving a signed JWT token.
                  

                

              


              

                
2

                

                  
Application Registration & SSN Encryption (AR Service)

                  
Citizen submits demographic details via POST /api/ar/register. SSN is encrypted with
                    AES-256 and an application.created event is committed to the Transactional Outbox.

                

              


              

                
3

                

                  
Data Collection (DC Service) & Kafka Dispatch

                  
Citizen inputs monthly salary, property income, household dependents, and medical expenses.
                    Finalizing publishes a Kafka event to the eligibility pipeline.

                

              


              

                
4

                

                  
Automated Eligibility Determination (ED Service)

                  
The rules engine checks income against federal poverty level limits and plan guidelines (e.g. SNAP,
                    Medicaid) to calculate benefit amounts.

                

              


              

                
5

                

                  
Benefit Issuance (BI), Notices (CO) & Aggregated Dashboards

                  
Approved claims trigger benefit account provisioning in BI, PDF notice creation in CO, and
                    real-time dashboard updates across Citizen and Caseworker BFF views.
